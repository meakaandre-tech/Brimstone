# Brimstone

An all-in-one optimisation mod for Minecraft 26.3 on Fabric, starting with a rewrite of the renderer. Built for the
SIFTEC modpack: it must draw exactly what vanilla draws, on old integrated graphics as well as new machines.

Work in progress: built one work package at a time from its design doc.
